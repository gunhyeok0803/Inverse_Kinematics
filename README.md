# WebXR IK

Meta Quest에서 컨트롤러 없이 맨손 핀치로 3D 로봇 팔의 끝을 잡고 움직이는 웹 VR 프로젝트입니다.
일반 조작과 정밀 조작의 차이를 수치로 비교하는 것이 목표이고, 설치 없이 브라우저 주소 하나로 엽니다.

## 데모

https://gunhyeok0803.github.io/Inverse_Kinematics/

| 기기 | 여는 방법 | 조작 |
|---|---|---|
| Meta Quest | Quest Browser에서 위 주소를 열고 오른쪽 아래 VR 버튼을 누른 뒤 컨트롤러를 내려놓습니다 | 맨손, 엄지와 검지를 붙이면 핀치 |
| PC | Chrome 같은 브라우저에서 위 주소를 엽니다 | 마우스 드래그로 둘러보기, W A S D로 이동 |

Quest에서는 기기 설정에서 손 추적이 켜져 있어야 합니다. 손 위치를 보여 주는 판은 처음에는 숨겨져 있고, 회색 DEBUG 버튼을 검지로 누를 때마다 보였다 숨겼다 합니다. PC에는 손이 없어서 버튼을 누를 수 없습니다.

## 사용 기술

| 구분 | 내용 |
|---|---|
| 언어 | JavaScript(ES 모듈), HTML |
| 3D와 VR | A-Frame 1.8.0, three.js r184(A-Frame 배포판 super-three), WebXR Device API와 Hand Input |
| 불러오기 | importmap으로 CDN에서 불러옵니다. 설치나 빌드 과정이 없습니다 |
| 배포 | GitHub Pages |
| 도구 | VS Code와 Live Server, Chrome 개발자 도구, Meta Quest Pro, Blender(로봇 모델) |

## PC에서 직접 실행

파일을 더블클릭해서 열면 모듈을 불러오지 못하므로 로컬 서버로 엽니다.

- VS Code: index.html을 연 뒤 오른쪽 아래 Go Live를 누릅니다.
- 터미널: 이 폴더에서 `python -m http.server 5500`을 실행하고 http://localhost:5500 을 엽니다.

Quest의 WebXR은 https에서만 열리므로 Quest에서는 데모 주소를 씁니다.

## 폴더 구성

```
index.html               importmap과 장면
js/main.js               aframe과 컴포넌트를 불러오는 진입점
js/components/           A-Frame 컴포넌트, 파일 하나에 컴포넌트 하나
js/lib/                  컴포넌트가 쓰는 계산 함수(벡터, 좌표 변환, 캡슐)
assets/models/           로봇 모델(GLB)
tools/                   로봇 모델을 다시 만드는 Python 스크립트(build_symphony5_drawing.py는 Blender에서 실행)
```

로봇은 심포니 5(푸른로보틱스) 6축 협동로봇의 공식 도면 치수로 Blender에서 만든 모델(`symphony-5-drawing.glb`)입니다. 관절 노드 joint1~joint6의 회전축은 차례로 y, x, x, x, y, x이고, 모든 관절각이 0이면 팔이 위로 곧게 서고 공구는 옆을 봅니다. 공구 끝 기준점 tcp는 공구 플랜지 면에서 4 cm 앞입니다. 관절 범위는 도면대로 joint3 ±160°, 나머지 ±360°입니다.

| 컴포넌트 | 역할 |
|---|---|
| env-info | 환경 확인 판(문제를 찾을 때만 씀, 장면에서는 쓰지 않음) |
| desk | 책상(윗판, 다리)을 만들고 로봇 장착점을 윗면 위 정한 자리에 놓습니다 |
| axes-helper | 엔티티의 좌표축을 그립니다 |
| hand-info | 손목과 검지 끝 위치, 핀치 상태를 판에 띄웁니다. 판이 숨겨져 있으면 글자를 바꾸지 않습니다 |
| robot-pose | 로봇 모델의 관절 각도를 도 단위로 정합니다 |
| robot-mvp | 공구 끝 주황 공을 핀치로 잡아 끌면 관절이 따라오게 하고 공구 끝 위치를 이벤트로 알립니다. 공구 끝은 책상과 로봇 몸(기둥, 위팔, 아래팔 캡슐)을 뚫지 않습니다 |
| tool-draw | 로봇 공구 끝이 지나간 자리에 선을 그리고 저장 버튼을 누르면 선을 모두 지웁니다 |
| tool-log | 공구 끝을 끄는 동안 손과 공구 끝 위치를 시간과 함께 기록하고 버튼을 누르면 CSV로 내려받은 뒤 기록을 비웁니다 |
| press-button | 검지 끝으로 누르는 가상 버튼입니다 |
| vr-exit-button | 버튼을 누르면 VR을 끝내고 브라우저 화면으로 돌아갑니다(장면에서는 쓰지 않음) |
| visible-toggle | 버튼을 누를 때마다 정한 엔티티를 보였다 숨겼다 합니다. DEBUG 버튼이 손 확인 판에 씁니다 |
| start-view | PC에서 처음 열 때 카메라가 내려다보는 각도를 정합니다 |
| joint-axes | 로봇 관절마다 좌표축을 띄우고 공구 끝 아래에 장면 좌표를 띄웁니다 |
| spin | 엔티티를 y축으로 돌립니다(확인용, 장면에서는 쓰지 않음) |

## 장면 배치

단위는 m이고 사용자는 시작 위치(0, 0, 0)에서 -z 방향을 봅니다. Quest에서는 높이 0이 실제 바닥입니다.

| 항목 | 값 |
|---|---|
| 바닥 | 4 x 4 |
| 책상 | 가로 1.2, 깊이 0.8, 높이 0.75, 앞 모서리 z = -0.35 |
| 로봇 장착점 | 윗면 왼쪽 뒤, 장면 기준 (-0.45, 0.75, -0.85). 로봇은 y축으로 70도 돌려 사용자 쪽 오른편을 봅니다 |
| 공구 끝 시작 위치 | 장면 기준 약 (0.12, 0.99, -0.67). 공구가 바로 아래를 봅니다 |
| 기록 저장 버튼 | 윗면 오른쪽 앞, 장면 기준 (0.42, 0.75, -0.53) |
| DEBUG 버튼 | 기록 저장 버튼 오른쪽 12 cm, 장면 기준 (0.54, 0.75, -0.53) |
| 손 확인 판 | 책상 오른쪽, 장면 기준 (0.85, 1.3, -0.9). 처음에는 숨겨져 있습니다 |

책상 치수는 index.html의 desk 속성에서만 바꿉니다. 장착점은 desk가 다시 계산하므로 치수를 바꿔도 윗면 위에 남습니다.
